# Galaxy for Android

Installable releases of the Galaxy app for Android TV, Google TV, Fire TV,
Android TV boxes, phones and tablets. This repository contains downloads only;
the source code is private.

## Install

The newest version is always at:

```
https://github.com/kmwhite40/galaxy-releases/releases/latest/download/galaxy-tv.apk
```

**Android TV / Fire TV:** install the free **Downloader** app (by AFTVnews), allow it to
install unknown apps, then enter the link above.

**Phone or tablet:** open the link in your browser and tap the downloaded file
(allow your browser to install unknown apps when asked).

**Command line (for example Termux):**

```
wget -O galaxy-tv.apk https://github.com/kmwhite40/galaxy-releases/releases/latest/download/galaxy-tv.apk
```

Each release also lists the APK's SHA-256 checksum, so you can verify the download.

## After installing

Open **Galaxy**. It looks for a Galaxy server on your network; if it does not find
one, enter the server address you were given. You need an account on that server
to sign in. Once installed, the app offers updates by itself.
